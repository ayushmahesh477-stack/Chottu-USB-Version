# 🦾 Chottu AI - Your Personal Jarvis

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Platform](https://img.shields.io/badge/Platform-Windows%20%7C%20Mac%20%7C%20Linux-blue)]()
[![Python](https://img.shields.io/badge/Python-3.8%2B-green)]()

**Chottu AI** is a fully portable, offline AI assistant that runs entirely from a USB drive. No installation needed, no traces left behind.

## ✨ Features

- 🚀 **Truly Portable** - Runs from USB, works on any computer
- 🔒 **100% Offline** - No internet needed after setup
- 🎤 **Jarvis Commands** - Open apps, find files, check system status
- 💬 **AI Chat** - Powered by Qwen 2.5 7B
- 💻 **Cross-Platform** - Windows, Mac, and Linux

## 🎮 Commands You Can Use

| Say This | Chottu Does |
|----------|-------------|
| `open notepad` | Opens Notepad |
| `open website google.com` | Opens Google |
| `find report` | Searches for files |
| `battery` | Shows battery percentage |
| `memory` | Shows RAM usage |
| `what time is it` | Tells current time |
| `who are you` | Introduces itself |

## 📋 Requirements

- **USB Drive:** 32GB or larger (64GB recommended)
- **RAM:** 8GB minimum
- **OS:** Windows 10/11, Mac, or Linux

## 📁 Folder Structure

USB Drive/
├── chottu_tools/ # Jarvis command system
├── install.bat # One-time installer
├── start-windows.bat # Launcher with voice commands
└── README.md # This file


## 🔧 First Time Setup

The first time you run `install.bat`, it will:
1. Download the AI engine (Ollama)
2. Download your chosen AI model (~4.7 GB)
3. Set up everything on your USB

**This takes 20-40 minutes depending on your internet speed.**

## ❓ Common Issues

| Problem | Solution |
|---------|----------|
| Installer fails | Re-run install.bat - it resumes downloads |
| Model too large | Format USB as exFAT (supports >4GB files) |
| Python not found | Install Python from python.org for voice commands |
