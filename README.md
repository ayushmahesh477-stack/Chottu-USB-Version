**Chottu AI** is a fully portable, offline AI assistant that runs entirely from a USB drive. It combines the power of Ollama with a Jarvis-like command system that can control your computer.

## ✨ Features

- 🚀 **Truly Portable** - Runs from USB, leaves no traces on host PC
- 🔒 **100% Offline** - No internet needed after setup
- 🎤 **Jarvis Commands** - Open apps, find files, check system status
- 💬 **AI Chat** - Powered by Qwen 2.5 7B (or any GGUF model)
- 🔓 **Uncensored Options** - Choose models without content filters
- 💻 **Cross-Platform** - Windows, Mac, and Linux support
- 🎯 **Privacy First** - No telemetry, no cloud, no tracking

## 🎮 Jarvis Commands

| Command | Action |
|---------|--------|
| `open notepad` | Launch any application |
| `open website google.com` | Open websites |
| `find report` | Search for files |
| `battery` | Check battery status |
| `memory` | Check RAM usage |
| `what time is it` | Get current time |
| `who are you` | About Chottu |

## 📋 Requirements

- **USB Drive:** 32GB+ (64GB recommended)
- **RAM:** 8GB minimum (16GB recommended)
- **OS:** Windows 10/11, Mac, or Linux
